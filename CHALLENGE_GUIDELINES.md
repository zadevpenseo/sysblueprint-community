# Panduan Tantangan Arsitektur (Challenge Guidelines)

Tantangan SysBlueprint dirancang untuk melatih kemampuan rekayasa sistem dunia nyata melalui pembuatan artefak yang dapat diuji dan dipamerkan sebagai portofolio profesional.

---

## 🚫 Kebijakan Infrastruktur: Non-Classroom

Berdasarkan jadwal resmi dari GitHub, layanan GitHub Classroom dihentikan (*sunset*) per 28 Agustus 2026. Oleh karena itu, SysBlueprint sepenuhnya menggunakan alur kerja terbuka berbasis **GitHub Template Repositories**:
* Tanpa perlu registrasi akun sekolah/institusi khusus.
* Hasil pekerjaan peserta sepenuhnya menjadi milik peserta di repositori GitHub pribadi masing-masing.

---

## 🔄 Alur Partisipasi Tantangan

1. **Pilih Tantangan Aktif**: Tinjau daftar tantangan di kategori [GitHub Discussions - Challenges](https://github.com/zadevpenseo/sysblueprint-community/discussions).
2. **Gunakan Template Proyek**: Klik tombol *Use this template* pada repositori template terkait, atau salin struktur berkas dari folder `resources/`.
3. **Bangun Solusi di SysBlueprint Studio**:
   * Desain skema data pada [sysblueprint.pages.dev](https://sysblueprint.pages.dev).
   * Validasi integritas relasi, batasan NOT NULL, dan konsistensi tipe data.
   * Uji diagram alur status SCXML pada simulator transisi interaktif.
4. **Dokumentasikan Solusi**: Lengkapi berkas `README.md` pada repositori proyek pribadi Anda sesuai panduan pada [project-readme-template.md](resources/project-readme-template.md).
5. **Kumpulkan Bukti**: Kirimkan tautan repositori Anda pada utas diskusi tantangan terkait untuk ditinjau oleh reviewer dan komunitas.

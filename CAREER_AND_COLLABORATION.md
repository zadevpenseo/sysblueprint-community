# Panduan Karir dan Kolaborasi Proyek

Kanal **Career & Collaboration** pada GitHub Discussions disediakan untuk membantu anggota komunitas menemukan rekan belajar, membangun tim kompetisi hackathon, atau berkolaborasi pada proyek sumber terbuka.

---

## 🤝 Format Pembukaan Utas Kolaborasi

Saat membuka utas pencarian rekan proyek, sertakan informasi terstruktur berikut:

```markdown
### [KOLABORASI] Nama Proyek / Topik Rancangan Sistem

* **Domain Sistem**: (contoh: Logistik Rantai Pasok, Rekam Medis, Fintech Escrow)
* **Kebutuhan Peran**: (contoh: Database Architect, Backend Engineer, QA Reviewer)
* **Target Waktu**: (contoh: 2 minggu / 1 bulan sprint santai)
* **Komitmen Jam**: (contoh: 3 - 5 jam per minggu secara asinkron)
* **Tautan Repositori / Draf Studio**: https://sysblueprint.pages.dev/...
* **Tujuan Akhir**: (contoh: Portofolio bersama, submisi jurnal, atau karya sumber terbuka)
```

---

## 💼 Presentasi Portofolio ke Dunia Industri

Rancangan sistem yang Anda selesaikan di SysBlueprint dapat dipamerkan langsung di CV, resume ATS, LinkedIn, atau portofolio pribadi:
* **Tautkan Bukti Nyata**: Berikan tautan langsung ke repositori GitHub proyek Anda yang memuat file DDL ANSI SQL dan diagram SCXML.
* **Fokus pada Dampak Arsitektural**: Jelaskan trade-off yang Anda pilih (misalnya: mengapa memilih normalisasi 3NF untuk integritas finansial alih-alih dokumen NoSQL).
* **Cantumkan Nilai Rubrik**: Tunjukkan bahwa karya Anda telah lolos telaah sejawat (*peer-reviewed*) dengan skor rubrik objektif.

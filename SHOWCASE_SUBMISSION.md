# Kriteria Pengajuan Galeri Portofolio (Showcase Submission)

Galeri Portofolio SysBlueprint menampilkan proyek terpilih dari komunitas yang mendemonstrasikan keunggulan arsitektural, ketertiban dokumentasi, dan kepatuhan standar industri.

---

## 🎯 Syarat Masuk Galeri Showcase

Agar sebuah proyek dapat dikurasi dan dipamerkan pada website resmi SysBlueprint:

1. **Skor Evaluator >= 85 (Predikat Distinction)**: Lolos verifikasi otomatis menggunakan skrip `scripts/rubric_grader.py`.
2. **Minimal 2 Telaah Sejawat (Peer Reviews)**: Telah menerima minimal 2 umpan balik substantif dari kontributor lain di GitHub Discussions atau PR.
3. **Izin Publikasi Eksplisit**: Penulis proyek secara sadar menyetujui penayangan ringkasan rancangan dan tautan repositori mereka pada galeri publik.
4. **Lisensi Terbuka yang Sah**: Repositori proyek mencantumkan lisensi publik (misalnya MIT, Apache 2.0, atau CC-BY 4.0).

---

## 📥 Cara Mengajukan Karya

1. Pastikan repositori proyek Anda bersifat publik.
2. Buat Issue baru dengan memilih template **Showcase Submission**.
3. Lampirkan:
   * Nama proyek dan nama tampilan penulis.
   * Ringkasan masalah bisnis/teknis dalam 1 kalimat pembuka.
   * Diagram arsitektur atau tangkapan layar skema dari SysBlueprint Studio.
   * Tautan repositori GitHub proyek Anda.
   * Tautan utas GitHub Discussions tempat peer review berlangsung.
